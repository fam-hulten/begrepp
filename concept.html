🧪 Test: Web Audio API (seamless playback)

Jämför playTwoFiles (HTML5 Audio, onended + ny Audio = glapp) mot playSeamless (Web Audio API, AudioBufferSourceNode.start(when) = exakt timing, inga glapp). Klicka på knapparna och kolla konsolen för tidsmätning mellan filerna.

📖 Forward reveal för "normer"
Kedja: #normer + audio-ar.mp3 + normer-forklaring.mp3. Samma 3 filer som appens forward reveal — testar seamless concat.
Variant X1 — HTML5 Audio (playTwoFiles-glapp)
Nuvarande playChain. Förväntat glapp: ~10-30ms mellan filer.
Variant X2 — Web Audio API (playSeamless)
Ny seamless-version. Förväntat glapp: ~0ms (exakt timing via AudioBufferSourceNode.start).
Variant X3 — Web Audio API, lång kedja (5 filer)
Stresstest: 5 filer i kedja för att se om glapp ackumuleras med HTML5 vs Web Audio.
Vad jag mäter: Tiden från det att fil N slutar tills fil N+1 börjar spela (ljudmässigt). Med HTML5 Audio: onended → ny Audio() → load → play() = ~50-200ms glapp per filövergång. Med Web Audio API: AudioBufferSourceNode.start(when) med exakt when = ~0ms glapp.

Hur man testar: Öppna DevTools → Console. Klicka på knappar och jämför konsolutdata. Lyssna också med hörlurar — ska vara sömlöst med X2, tydliga pauser med X1.
